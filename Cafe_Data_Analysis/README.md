# 🛒 Olist-Cohort-Retention-Analysis: 가설 기반 분석 및 실전 데이터 검증

> **가설 기반 분석 프레임워크를 설계**하고, 이를 **10만 건 규모의 실제 이커머스 데이터(Olist)**에 적용하여 분석 파이프라인의 신뢰성을 검증한 프로젝트입니다.

---

## 📅 프로젝트 정보
- **수행 기간**: 2024.12.23 ~ 2025.01.05 (약 2주)
- **핵심 목표**: 리텐션(Retention) 및 ROAS 분석 로직 설계 후 실제 대규모 트랜잭션 데이터를 통한 가설 검증

## 🛠 기술 스택 (Tech Stack)
- **Language**: Python 3.x
- **Database**: SQLite (Data Mart 설계)
- **Library**: Pandas, Seaborn, Matplotlib
- **Analysis**: Cohort Analysis, Marketing ROAS Analysis

---

## 🚀 주요 수행 내용

### 1. 가설 기반 분석 프레임워크 설계
- **로직 시뮬레이션**: 실전 데이터 대입 전, 분석 로직(코호트 잔존율 및 ROAS 계산식)을 선제적으로 설계하여 분석의 정밀도 확보.
- **데이터 마트 설계**: `SQLite`를 활용하여 10만 건 이상의 데이터를 처리하기 위한 '주문-결제-고객' 중심의 관계형 데이터 모델링.

### 2. 실전 데이터 적용 및 검증
- **대규모 데이터 처리**: Kaggle Olist Dataset(약 10만 건)을 연동하여 설계한 SQL 쿼리 및 분석 파이프라인의 확장성 확인.
- **지표 산출**: `WITH`절(CTE), `strftime`, `CAST` 함수 등을 사용하여 월별 코호트 잔존율과 채널별 마케팅 효율 실측치 도출.

### 3. 결과 시각화 및 인사이트
- **Retention Heatmap**: 실제 데이터의 급격한 고객 이탈 구간(가입 1개월 차 잔존율 1% 미만)을 시각화하여 현실적인 비즈니스 지표 특성 체감.
- **ROAS Bar Chart**: 매체별 투자 대비 수익률을 비교하여 감에 의존하지 않는 데이터 기반의 예산 최적화 근거 마련.

## 📊 분석 결과 요약 (Real-world Insight)
1. **가설 검증**: "주기적인 재구매가 일어날 것"이라는 가설과 달리, 실전 데이터에서는 초기 이탈률이 매우 높음을 확인하며 CRM 마케팅의 중요성 도출.
2. **성과 측정**: 채널별 ROAS 분석 결과, 광고비 지출 규모와 성과가 반드시 비례하지 않음을 수치로 증명하여 효율 중심의 매체 운용 제안.

## 🏆 성과 및 배운 점
- **분석 프로세스의 정교화**: 가상 설계와 실전 검증을 연결하여 **분석 결과의 신뢰도를 확보**하는 End-to-End 파이프라인 구축.
- **대규모 데이터 핸들링**: 10만 건 이상의 트랜잭션 데이터를 처리하며 **SQL 가공 및 데이터 정합성** 유지 역량 확보.
- **문제 해결 능력**: 실제 데이터 적용 시 발생하는 타입 오류 및 식별자 문제를 AI 툴을 활용해 스스로 디버깅하며 독립적인 프로젝트 수행 능력 배양.
