# 모두의 운전석 — 운전자 특성에 맞춰 차량 정보를 '다른 감각'으로 전달하는 접근성 운전 보조 앱

> **한 줄 소개**: 색(신호등), 소리(경고음·방향지시등·내비 음성·사이렌), 작은 경고등처럼 **한 가지 감각에만 의존하는 차량 정보**를
> 색각이상·청각장애·저시력·주의력 저하(고령) 운전자가 받아들일 수 있는 **소리 패턴·음성·화면 깜빡임·큰 글씨**로 바꿔 전달하는 Pleos Connect 앱

⚠️ 보조 기능입니다. 안전장치가 아니며, 운전자는 언제나 직접 신호와 주변을 확인해야 합니다.

---

## 실행 방법

### APK 설치 (바로 실행)
```bash
adb install apk/팀명_모두의운전석_release.apk
```
앱 목록에서 **모두의 운전석**을 실행합니다. 처음 실행 시 차속·알림 권한(청각장애 프로필은 마이크 권한도)을 허용합니다.

### 소스 빌드
```bash
./gradlew :core:test           # 단위·시나리오 테스트 90개 (Android SDK 불필요)
./gradlew :demo:run            # PC 데모: 시나리오별 알림 로그, 신호 검출 정확도, 영상 처리 비율·처리 시간
./gradlew :app:assembleRelease # APK (ANDROID_HOME 또는 local.properties 필요)
```

### 시연 영상
- `docs/시연영상/모두의운전석_시연.mp4` (3분 34초, 가로): `./gradlew :demo:renderVideo`
- `docs/시연영상/모두의운전석_센텀시티.mp4` (85초, 부산 센텀시티 실제 도로 주행): `./gradlew :demo:renderCentum`
- `docs/시연영상/모두의운전석_숏폼.mp4` (37초, 세로 숏폼): `./gradlew :demo:renderShorts`
- 챕터, 내레이션 대본, 숏폼 게시글 예시는 `docs/시연영상/README.md`에 있습니다.

### 시연 순서 (에뮬레이터)
1. 화면 아래 **모드**에서 `시뮬레이션: …` 시나리오 7종 중 하나를 고릅니다. 시나리오에 맞는 운전자 특성이 자동으로 선택됩니다.
2. **운전자 특성**(색각이상·청각장애·저시력·주의력·고령)을 바꿔, 같은 상황에서 알림 방식이 달라지는 것을 확인합니다.
3. **알림 배우기** 버튼으로 각 알림의 소리와 의미를 들어 봅니다. **↻ 다시 듣기**는 마지막 알림을 다시 전달합니다.
4. `실차: 차량 경고·내비 (카메라 없이)` 모드에서는 Pleos 에뮬레이터 Virtual Console로 도어·방향지시등·좌석·조명을 바꿔 봅니다.
   에뮬레이터는 차속을 시뮬레이션하지 못하므로, 차속이 들어오지 않으면 **시연용 차속** 막대가 나타납니다.

## 무엇을 해결하나

| 운전자 | 차량이 주는 정보의 문제 | 이 앱이 바꿔 주는 방식 |
|---|---|---|
| **색각이상** | 신호등 적·녹·황을 색으로만 구분 | 신호 변화를 **음높이 패턴 + 음성 + 모양 기호(■▲●←)** 로. 좌회전 화살표가 **내 경로**에 해당하는지도 내비와 맞춰 알려줌 |
| **청각장애** | 벨트 경고음, 방향지시등 똑딱 소리, 내비 음성, **긴급차량 사이렌** | **화면 전체 깜빡임 + 큰 글씨 + 헤드업 알림**. 실내 마이크로 사이렌을 감지해 "길을 양보하세요" |
| **저시력** | 계기판 경고등·아이콘이 작음 | 타이어 저압·전조등 미점등·벨트 등을 **음성**으로 읽어주고 글씨 1.4배 |
| **주의력·고령** | 깜빡한 방향지시등, 초록불 늦은 출발, 뒷좌석 아이 방치, 알림이 겹치면 혼란 | **한 번 더 상기**하되, 동시에 여러 알림이 나오지 않도록 **중재** |

## 핵심 설계 원칙 (안전을 위해 일부러 이렇게 만든 부분)

| 원칙 | 내용 | 왜 |
|---|---|---|
| **안전 우선 비대칭 확정** | 초록불·좌회전 화살표는 5프레임 중 4프레임 + 높은 신뢰도일 때만 확정, 빨간불·황색은 3프레임이면 확정. 동률이면 정지 쪽 | 색각이상 운전자에게 가장 위험한 오류는 "빨간불인데 초록불이라고 알려주는 것" |
| **실제 거리 기반 판단** | 300mm 등화의 화면 크기로 신호등까지 거리 추정 → 정지선에 서는 데 필요한 감속도(v²/2d)가 2.5 m/s² 이상이고 운전자가 감속하지 않을 때만 긴급 경고 | 멀리 있는 빨간불에 긴급 경보를 울리면 운전자가 경고를 무시하게 됨 |
| **황색 딜레마 구간** | 반응 시간 1초를 빼고 편안한 감속(3 m/s² 이하)으로 설 수 없으면 "급정거하지 말고 주의해서 진행하세요" | 정지선 직전 황색에 "정지하세요"는 급정거와 뒤차 추돌을 부름 |
| **교차로 진입 후 침묵** | 이미 정지선을 지났으면 적색 경고를 하지 않음 | 교차로 안에서 경보가 울리면 오히려 위험 |
| **실패를 숨기지 않음** | 접근할 때 보이던 신호등이 정차 후 화면에서 사라지면 "신호를 직접 확인하세요" | 침묵을 "아직 빨간불"로 오해하지 않게 |
| **반응 시간 반영** | 긴급 경고 시점에 운전자 반응 시간(기본 1.0초, 고령 1.5초, 청각장애 1.3초)을 포함 | 알림을 받고 실제로 브레이크를 밟기까지 시간이 걸림 |
| **알림 중재** | 같은 순간엔 가장 중요한 알림만 소리·음성·깜빡임, 긴급 경고 직후 4초는 덜 중요한 알림을 화면에만, 음성 간격 2초. 경고 이상은 항상 전달 | 알림이 겹치면 정말 중요한 것을 놓침 (주의력·인지 부담) |
| **눈부심·광과민성 배려** | 화면 깜빡임은 초당 3회 미만, 야간에는 밝기 45% | 청각장애 운전자의 주 채널이 깜빡임이므로 안전하게 |
| **필요할 때만 영상 처리** | 신호등을 최근에 봤거나, 저속이거나, 내비 안내 지점 근처일 때만 매 프레임, 그 외에는 초당 2장 | 주행 중 CPU 사용률 기준 대응 |

## 경고 인지성 설계 (실제로 알아채고 반응할 수 있게)

| 원칙 | 구현 |
|---|---|
| **소리와 음성이 겹치지 않게** | 알림음이 끝난 뒤 음성이 나옵니다. 동시에 나오면 서로 가려 둘 다 알아듣기 어렵습니다 |
| **소음에 묻히지 않는 소리** | 순음(사인파) 대신 기본음 + 2·3·4배음을 섞은 소리. 일부 주파수가 도로 소음·음악에 가려도 들립니다 |
| **고령자 청력에 맞춘 음역** | 노인성 난청은 고음부터 안 들리므로, 주의력·고령 프로필은 알림음 전체를 0.6배 낮은 음으로 (최고 기본음 650Hz 이하) |
| **위험도에 따라 크기·리듬·깜빡임이 커짐** | 안내 < 주의 < 경고 < 긴급 순으로 소리 크기 증가. 깜빡임: 안내는 테두리만, 주의 1회, 경고 2회, 긴급 5회 (모두 초당 3회 이하, 광과민성 기준) |
| **짧고 핵심어가 먼저 나오는 음성** | "빨간불! 감속하세요!"처럼 일상어(빨간불·노란불·초록불)를 맨 앞에. 긴급은 1.15배 빠르게, 고령자는 0.9배 천천히 |
| **한눈에 읽히는 깜빡임** | 화면 깜빡임에는 한두 단어("감속!", "벨트", "사이렌")를 크게, 문장은 작게 |
| **깜빡임을 놓쳐도 남는 표시** | 벨트 미착용·사이렌·문 열림·방향지시등·빨간불 감속 필요처럼 계속되는 위험은, 상황이 끝날 때까지 화면 위쪽에 천천히 밝기가 변하는 표시줄로 남깁니다 (도로를 보느라 깜빡임을 놓친 청각장애 운전자용) |
| **반응 시간을 고려한 경고 시점** | 긴급 경고는 '알림을 받고 반응한 뒤에도 강한 제동이 필요한가'로 판단. 반응 시간: 기본 1.0초, 고령·주의력 1.5초, 청각장애(화면으로만 받음) 1.3초 → 고령자는 더 일찍 경고 |
| **긴급 경고는 음악을 멈춤** | 긴급은 오디오 포커스를 잠시 가져와 음악을 멈추고, 나머지는 음악 볼륨만 낮춥니다 |

참고한 기준: 청각 경고음 설계(배음이 풍부한 소리, 위험도에 따라 빨라지는 리듬), 웹 접근성 광과민성 기준(초당 3회 이하), 운전 중 시선 분산 가이드라인(짧은 글랜스로 읽히는 정보).

## 알림 규칙

화면 문장과 음성 문장은 다릅니다. 음성은 더 짧고 핵심어가 먼저 나옵니다 (예: 화면 "빨간불! 즉시 감속하세요." → 음성 "빨간불! 감속하세요!").

| 상황 | 알림 | 소리 패턴 |
|---|---|---|
| 정차 중 적/황 → 녹 | "초록불로 바뀌었습니다." | 도→솔 (올라감) |
| 녹색인데 3초 넘게 출발 안 함 | "초록불입니다. 주변을 확인하고 출발하세요." (1회) | 도→솔 |
| 주행 중 황색, 정지 가능 | "노란불입니다. 정지를 준비하세요." | 한 번 길게 |
| 주행 중 황색, 정지선이 너무 가까움 | "노란불입니다. 급정거하지 말고 주의해서 진행하세요." | 한 번 길게 |
| 주행 중 적색 | "빨간불입니다. 정지하세요." | 높음→낮음 3번 (내려감) |
| 적색인데 반응 시간을 고려하면 강한 제동이 필요하고 감속 안 함 | "빨간불! 즉시 감속하세요." (3초마다, 제동하면 멈춤) | 빠른 연속음 |
| 정차 후 신호등이 화면에서 사라짐 | "신호등이 보이지 않습니다. 신호를 직접 확인하세요." | 차임 |
| 좌회전 화살표 점등 | 경로가 좌회전이면 "안내 경로도 좌회전입니다", 직진이면 "직진은 기다리세요" | 차임 / 도→솔 |
| 주행 중 벨트 미착용 / 문 열림 | "안전벨트를 매 주세요." / "문이 열려 있습니다!" | 같은 음 두 번 / 연속음 |
| 방향지시등 20초 이상 켜짐 (30km/h↑, 안내 지점 근처 아님) | "방향지시등이 계속 켜져 있습니다." | 같은 음 두 번 |
| 어두운데 전조등 꺼짐 / 타이어 저압 | 1회 안내 | 같은 음 두 번 |
| 긴급차량 사이렌 (청각장애 프로필) | "긴급차량 사이렌이 들립니다. 주변을 살피고 길을 양보하세요." | 화면 깜빡임 |
| 주차(P) 또는 문 열림 + 이번 주행에 뒷좌석 탑승 | "내리기 전에 뒷좌석을 확인하세요." | 한 번 길게 |
| 내비 안내 지점 300m·100m 전 | "300m 앞 좌회전 (강남대로)" 큰 카드 | 차임 |
| 정차 중 적색 / P·R 기어 | 알리지 않음 (화면 표시만) | — |

**프로필별 출력**: 청각장애만 고르면 소리·음성 없이 화면 깜빡임 + 헤드업 알림, 저시력·주의력은 큰 글씨, 경고(WARNING) 이상은 모두에게 화면 깜빡임.

## 장애 사용자를 위한 사용성

- **질문형 첫 설정 + 내 귀에 맞춘 소리**: 처음 실행하면 장애 이름 대신 상황으로 묻습니다 ("빨간불과 초록불을 구분하기 어려우신가요?" 등 4개). 이어서 차 스피커로 소리 3가지(보통·낮은·작은 소리)를 들려주고 들렸는지 묻습니다.
  - 낮은 소리만 들리면: 낮은 음역으로
  - 작은 소리를 못 들으면: 1.25배 크게
  - 청각장애인데 큰 소리는 들리면(부분 난청): 화면 깜빡임에 알림음도 함께
  - 아무것도 못 들으면: 화면 알림을 자동으로 켬
- **알림 양 3단계**: 위험할 때만 / 보통 / 자세히. "보통"은 알림마다 처음 3번만 소리의 뜻을 덧붙이고("두 음이 올라가면 초록불입니다"), 익숙해지면 짧게 줄입니다. 운전하면서 소리를 익히는 방식입니다.
- **알림별 끄기**: 필요 없는 안내는 주차 중에 배너에서 끌 수 있습니다. 경고 이상, 노란불, 신호 놓침 알림은 끌 수 없고, "위험할 때만"에서도 유지됩니다.
- **"? 지금 신호" 버튼**: 교차로에서 헷갈릴 때 누르면 현재 신호를 말해 줍니다. 최근 프레임의 80% 이상이 일치하면 "지금은 빨간불입니다. 신호등까지 약 25미터.", 애매하면 "빨간불로 보이지만 확실하지 않습니다. 직접 확인하세요.", 못 봤으면 "직접 확인하세요."라고 말합니다. **모르면서 아는 척하지 않습니다.**

- **알림 배우기**: 프로필에 해당하는 알림만 골라 소리(또는 화면)와 의미를 한 문장으로 들려줍니다. 예) "두 음이 올라가면 초록불입니다."
- **다시 듣기**: 마지막 알림을 프로필의 모든 감각으로 다시 전달합니다. 중재 때문에 화면에만 떴던 알림도 포함하며, 터치 영역은 76dp 이상입니다.
- **주행 중 단순화 화면**: 주행 중에는 설정을 숨기고 큰 상태 표시와 다시 듣기 버튼만 남깁니다(CarUxRestrictions).
- **화면 낭독기 지원**: 신호 패널이 현재 상태를 설명하고, 버튼·체크박스에 설명이 있습니다.
- **주행 요약**: 주차하면 "주행 12분 · 신호 안내 6회 · 긴급 0회" 같은 요약을 보여주고, 가족·보호자에게 공유할 수 있습니다. 위치는 기록하지 않고 기기에만 저장합니다.

## 실제 도로 검증 — 부산 해운대구 센텀시티

OpenStreetMap 실제 도로·차로·신호등 위치로 SUMO 교통 시뮬레이션을 돌리고(주변 차량 포함), 해운대로 1.76km(신호 12곳)를 달린 기록을 엔진에 그대로 넣었습니다 (`sim/`).

| 시각 | 알림 | 상황 |
|---|---|---|
| 13.0초 | 노란불, 정지 준비 | 해운대로 · 센텀북대로 |
| 15.2초 | 빨간불, 정지 | 일찍·부드럽게 감속하는 정상 정차 (긴급 경고 없음) |
| 60.3초 | 초록불로 바뀜 (+ 소리 뜻 덧붙임) | |
| 113.6초 → 116.6초 | 정지 안내 → **긴급 경고** | 빨간불을 못 보고 50km/h로 접근 (운전자 제동 117.4초 → 정지선 앞 정지) |
| 172.3초 | 빨간불, 정지 | 해운대로 · 센텀남대로 |
| 210.3초 → 213.3초 | 초록불 → 늦은 출발 리마인드 | |

실제 도로에서 시험하며 **거짓 긴급 경고 3가지를 찾아 고쳤습니다**:
- 거리를 잴 수 없을 만큼 먼 신호는 긴급이 아님 → 일반 정지 안내
- 15km/h 미만에서는 긴급 경고 안 함 → 초록불로 바뀌어 출발하는 순간(초록 확정 0.4초 전)의 거짓 경보 제거
- 횡단보도 신호 바로 뒤의 교차로 신호처럼 여러 신호가 보일 때 더 제한적인 신호를 기준으로

※ 신호 주기는 SUMO가 만든 값으로 실제 부산 신호 주기와 다릅니다. 지도 데이터 © OpenStreetMap contributors (ODbL).

## 검증 결과 (합성 데이터 기준)

- 테스트 90개 통과 (검출기, 상태 확정, 신호·차량·내비 알림, 중재, 사이렌, 영상 처리 조절, 주행 요약, 시나리오 E2E)
- 단일 프레임 신호 검출: 무작위 합성 장면 600장에서 정확도 99.7%, **다른 색으로 오인 0건**, 좌회전 화살표 76/77
- 거리 추정 오차: 중앙값 0.4%, 90% 지점 2.1%
- 사이렌 감지: 오르내림음(wail)·빠른 yelp·먼 거리 사이렌을 3초 안에 감지. 도로 소음, 일정한 경적, 음악 멜로디, 말소리는 감지하지 않음
- 영상 처리 시간 (데스크톱 JVM): 960px 4.3ms, 480px 1.2ms. 신호등 없는 구간 순항 중에는 처리량 1/5

합성 데이터는 실제 도로·실내보다 쉽습니다. 위 수치는 상한으로 보고, 실제 영상·녹음으로 다시 검증해야 합니다.

## 카메라가 없는 문제

Pleos 공개 API에는 카메라가 없어서, 신호 인식은 영상 입력을 `FrameSource` 인터페이스로 분리하고 **합성 영상**으로 검증했습니다.
카메라 접근이 열리면 CameraX 결과를 `Frame`으로 바꾸는 구현만 추가하면 되고(`Bitmap.toFrame()` 있음), 나머지는 그대로입니다.
차량 경고·내비 카드·사이렌 기능(청각·저시력·주의력)은 카메라 없이 **지금 SDK만으로 동작**합니다.

## 개인정보

- 위치를 기록하지 않습니다. 주행 요약은 기기 안에만 저장하고, 공유는 사용자가 직접 누를 때만 합니다.
- 마이크는 청각장애 프로필에서만 켜고, 소리를 기기 안에서 바로 분석합니다. 녹음 파일을 만들거나 전송하지 않습니다.
