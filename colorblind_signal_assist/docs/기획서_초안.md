## 1. 앱 한 줄 소개

**색·소리·작은 경고등에 의존하는 차량 정보를, 운전자 특성(색각이상·청각장애·저시력·주의력 저하)에 맞는 다른 감각으로 바꿔 전달하는 접근성 운전 보조 앱**

## 2. 기획 배경

자동차는 운전자에게 정보를 줄 때 **한 가지 감각에만 의존하는 경우가 많습니다.**

| 정보 | 의존하는 감각 | 받기 어려운 운전자 |
|---|---|---|
| 신호등 적·녹·황 | 색 | 색각이상 |
| 벨트 경고음, 방향지시등 똑딱 소리, 내비 음성 안내 | 소리 | 청각장애 |
| 계기판의 작은 경고등·아이콘 | 작은 시각 기호 | 저시력, 고령 |
| "방향지시등 껐나?", "뒷좌석 확인했나?" | 기억·주의 | 주의력 저하, 고령 |

대상 규모 (출처 있는 수치만 사용):
- **색각이상**: 아동·청소년 대상 전 세계 메타분석에서 남성 4.38%, 여성 0.64%로 추정됩니다(2025). 국내 초등학생 연구에서는 남학생 3.8%로 보고되었습니다(1999, 소규모 표본).
- **청각장애**: 2024년 말 등록장애인은 263만 1,356명이고 그중 청각장애가 16.8%입니다(보건복지부). 비율로 계산하면 약 44만 명입니다(추정).
- **고령 운전자** `[확인 필요: 원문 출처]`: 65세 이상 운전면허 소지자는 2022년 438만여 명이고(경찰청 자료 인용 보도), 국회입법조사처는 2025년 498만 명으로 추산했습니다. 고령 운전자 교통사고는 2025년 4만 5,873건으로 전년보다 8.3% 늘었습니다.

이 운전자들은 대부분 면허를 갖고 정상적으로 운전하지만, **차량이 정보를 주는 방식**이 이들에게 맞지 않아 매번 불편과 위험을 감수합니다.
스마트폰 앱은 차량 상태(벨트·문·방향지시등·좌석)와 내비 경로를 알 수 없어서 이 문제를 풀지 못합니다. **차량 데이터에 접근할 수 있는 인포테인먼트 앱**이어야 해결할 수 있습니다.

## 3. 주요 기능 및 차량 특화 요소

운전자가 처음에 자기 특성을 고르면(여러 개 가능), 앱이 **켤 기능**과 **알림을 전달할 감각**을 정합니다.

| 기능 | 대상 | 차량 데이터 | 전달 방식 |
|---|---|---|---|
| **신호 변화 알림** — 초록불 전환, 늦은 출발 리마인드, 황색 주의, 적색 정지, 적색 고속 접근 긴급 경고 | 색각이상, 주의력 | 영상 + 차속 + 감속도 | 신호별 고유 음높이 패턴(진행=올라감, 정지=내려감), 음성, 모양 기호(■▲●) |
| **경로 맞춤 좌회전 신호** — 좌회전 화살표가 켜졌을 때 내 경로가 좌회전인지 직진인지 함께 안내 | 색각이상 | 영상 + NaviHelper 경로 | 음성 + 화살표 기호 |
| **소리 경고 시각화** — 벨트 미착용, 주행 중 문 열림 | 청각장애, 저시력 | Vehicle State | 화면 전체 깜빡임 + 큰 글씨 + 헤드업 알림 |
| **방향지시등 깜빡함 알림** — 20초 이상 켜져 있고 30km/h 이상, 안내 지점 근처가 아닐 때 | 청각장애(똑딱 소리를 못 들음), 주의력 | Vehicle State + 차속 + NaviHelper | 화면 깜빡임 / 음성 |
| **내비 안내 카드** — 안내 지점 300m·100m 전에 "300m 앞 좌회전 (강남대로)" | 청각장애(음성 안내를 못 들음), 주의력 | NaviHelper | 큰 카드 + 헤드업 알림 |
| **작은 경고등 읽어주기** — 타이어 저압, 어두운데 전조등 꺼짐 | 저시력, 고령 | Vehicle State | 음성 + 1.4배 글씨 |
| **뒷좌석 확인** — 이번 주행에 뒷좌석에 사람이 있었고, 주차하거나 문을 열 때 | 모든 운전자 (아이·반려동물 방치 예방) | Vehicle State 좌석 탑승 | 음성 + 화면 |

**차량 특화 요소**
- **차량 맥락으로 알림을 거릅니다.** 정차 중 적색, P·R 기어일 때는 알리지 않고, 제동 중이면 반복 경고를 멈춥니다. 알림이 많으면 무시하게 되므로, 위험할 때만 강하게 알립니다.
- **여러 차량 신호를 결합합니다.** 방향지시등 + 차속 + 내비 안내 거리를 함께 봐서, 회전하려고 켠 경우와 끄는 것을 잊은 경우를 구분합니다.
- **화면을 보지 않아도 됩니다.** 알림 엔진은 포그라운드 서비스로 돌아가며 소리·음성·헤드업 알림으로 전달합니다. 주행 중에는 화면을 큰 상태 표시만 남기고 설정 UI를 숨깁니다(CarUxRestrictions 준수).
- **색에 의존하지 않는 화면**: 신호를 실제 신호등과 같은 위치에 표시하고, 정지=팔각형, 주의=삼각형, 진행=원, 좌회전=화살표 모양과 "정지·주의·진행" 문구를 함께 씁니다. 색은 색각이상 친화 팔레트(Okabe-Ito)를 씁니다.

## 4. 주요 사용 시나리오

앱에 시나리오 5종이 들어 있어 에뮬레이터에서 그대로 시연할 수 있습니다.

1. **색각이상 · 정차 후 출발**: 황색 신호에 "황색 신호입니다. 정지를 준비하세요" → 정차 → 초록불 전환 0.2초 후 "초록불로 바뀌었습니다"(도→솔) → 3초가 지나도 출발하지 않자 "주변을 확인하고 출발하세요".
2. **색각이상 · 적색 신호 놓침**: 45km/h로 적색 교차로에 접근 → 적색 인식 즉시 빠른 연속음과 "적색 신호! 즉시 감속하세요" → 제동할 때까지 3초마다 반복 → 제동하면 멈춤.
3. **색각이상 · 야간 좌회전**: 밤에 적색 + 좌회전 화살표가 함께 켜짐. 내비 경로가 좌회전이라 "좌회전 신호입니다. 안내 경로도 좌회전입니다".
4. **청각장애 · 소리 경고 시각화**: 벨트를 매지 않고 출발하자 화면이 깜빡이며 "안전벨트를 매 주세요" → 내비 음성 대신 "250m 앞 좌회전 (강남대로)", "100m 앞 좌회전" 카드 → 좌회전 후 방향지시등이 계속 켜져 있자 "방향지시등이 계속 켜져 있습니다" → 타이어 저압 경고. **소리 없이 모두 화면으로 전달됩니다.**
5. **주의력·저시력 · 야간 도착**: 전조등을 켜지 않고 출발하자 음성 안내 → "90m 앞 목적지" → 주차(P)하자 "내리기 전에 뒷좌석을 확인하세요".

### 현재 구현 상태 (제출 시점)
- 신호 인식(색 기반 검출 + 프레임 다수결 안정화), 신호·차량·내비 알림 규칙, 운전자 프로필별 출력 결정을 **Android와 분리된 순수 Kotlin 모듈**로 구현했습니다. 단위·시나리오 테스트 34개가 통과합니다.
- Pleos Connect 앱: 포그라운드 서비스 알림 엔진, 주행 중 단순화 화면, 프로필 선택, 패턴별 합성음, 한국어 음성, 헤드업 알림, 화면 깜빡임을 구현했습니다. release APK를 빌드했습니다.
- 카메라 대체: 국내 가로형 4구 신호등과 방해 요소(앞차 브레이크등, 가로등, 가로수)를 넣은 합성 영상을 만들었습니다. 무작위 600장에서 정확도 99.7%이고 다른 색으로 오인한 경우는 0건입니다.

### 본선까지 (1차 발표 ~ PT, 약 10일)
1. Vehicle State SDK 호출을 연결하고 Pleos 에뮬레이터 Virtual Console로 벨트·도어·방향지시등·좌석 시나리오를 검증합니다.
2. NaviHelper `getTBTInfo`를 연결해 실제 경로로 안내 카드와 좌회전 판단을 검증합니다.
3. 성능 기준을 맞춥니다(주행 중 CPU 사용률 제한). 카메라가 없는 실차 모드는 영상 처리를 하지 않으므로 부하가 거의 없고, 영상 처리는 처리 해상도와 주기를 낮출 수 있게 해 두었습니다.

### 카메라 한계와 단계적 전략
- **1단계 (지금)**: 카메라 없이 Vehicle State + NaviHelper만으로 동작하는 기능(청각·저시력·주의력)을 제공합니다. 신호 인식은 합성 영상으로 검증합니다.
- **2단계**: 차량 카메라 API가 열리면 `FrameSource` 구현 하나만 추가해 신호 인식을 실제 영상으로 전환합니다. 블랙박스 영상으로 오인식률(특히 녹색↔적색 혼동)을 측정하고, 필요하면 경량 객체 검출 모델로 교체합니다.
- **대안**: 실시간 신호 정보(신호 현시) 데이터를 위치와 함께 쓰면 카메라 없이도 신호 상태를 알 수 있습니다. `[확인 필요]` 공공 신호 정보 API의 제공 지역과 이용 조건을 확인합니다.

## 6. 기대효과 및 발전 가능성

### 타깃
- 1차: 색각이상, 청각장애, 저시력, 고령 운전자와 그 가족 (차량 구매 시 가족이 설치해 주는 경우 포함)
- 2차: 모든 운전자 (뒷좌석 확인, 방향지시등 깜빡함 알림은 누구에게나 유용)

### 예상 MAU (가정 기반 추정)
`[확인 필요]` 아래 수치는 모두 가정이며, 근거와 함께 고쳐 쓰세요.
- Pleos Connect 탑재 차량: 2027년 말 50만 대 (가정)
- 대상 운전자 비율: 색각이상 약 2.5%(남녀 평균) + 청각장애 약 0.9%(44만 명 / 인구) + 고령 운전자 약 10%(가정) ≈ 13%
- 대상 중 설치율: 15% (가정)
- **예상 MAU ≈ 50만 × 13% × 15% ≈ 1만 명**

### Retention
- 설정 후에는 **매 주행 자동으로 동작**하는 백그라운드 서비스라 따로 열 필요가 없습니다. 장애 특성은 바뀌지 않으므로 한번 맞으면 계속 씁니다.
- 위험할 때만 알리는 설계로 알림 피로를 줄여 삭제를 막습니다.

### 확대 계획
1. Pleos App Market 출시 → 장애인 단체·운전 재활 기관과 함께 사용자 검증
2. 차량 카메라·HUD·햅틱(시트·스티어링) API가 열리면 출력 채널 확장 (청각장애 운전자에게 진동 알림)
3. 사이렌·경적 감지(외부 마이크), 신호 잔여시간 안내로 기능 확대
4. 렌터카·카셰어링 차량 기본 탑재 (내 차가 아니어도 같은 설정을 계정으로 불러오기)
5. 접근성 규제·인증이 강화되는 해외 시장으로 확대
