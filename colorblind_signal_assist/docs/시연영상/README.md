# 시연 영상

`SixthSense_시연.mp4` — 1280×720, 30fps, 3분 42초, 알림음 포함

- 앱과 **같은 판단 엔진**(`DrivingAssistEngine`)으로 시나리오를 돌려 렌더링했습니다. 알림 시점·전달 감각·문구는 실제 앱 동작과 같습니다.
- 시나리오 1은 **부산 해운대구 센텀시티 실제 도로**(OpenStreetMap 도로·신호 위치 + SUMO 교통 시뮬레이션)에서 달린 기록입니다. 전방 시점은 OpenStreetMap 실제 건물 613개를 높이대로 세운 **3D 재현**이고, 신호 인식기가 이 3D 화면을 보고 판단합니다. 신호 주기는 시뮬레이션 생성값입니다.
- 전방 영상은 **합성 영상**입니다 (Pleos 공개 API에 카메라 미제공). 영상 안에 이 사실을 표기했습니다.
- 알림음은 앱의 실제 소리 패턴입니다. 음성 안내는 자막("음성 안내 …")으로 표시했습니다.
- 다시 만들기: `./gradlew :demo:renderVideo` (ffmpeg, 나눔 글꼴 필요)

# 내비와 함께 쓰기 시연

`SixthSense_내비와함께.mp4` — 1280×720, 1분 47초, 알림음 포함

- 운전자는 **내비 화면**을 보고, 신호 알림은 **내비 위 카드**로 뜹니다. 지도는 센텀시티 실제 지도(OpenStreetMap)로 그린 **예시 내비 화면**이며 실제 내비 앱이 아닙니다 (화면에 표시).
- 카드의 제목·문장·버튼·아이콘·표시 시간은 앱 코드(`AlertNotifier.buildCard`)가 센텀 주행 트레이스에서 실제로 만든 값입니다(Robolectric, `NavCompanionTest.recordNavCards`). 카드 모양은 차량 헤드업 알림을 본뜬 그림입니다.
- 구성: 문제 제기 → 시동 시 자동 시작(상태 알림) → 센텀 주행(노란불·빨간불 카드, 정차 중 상태 알림의 "지금 신호" 누름 → 답 카드, 초록불, 빨간불 긴급 감속 8초 카드) → 정리.

# 0.2.0 실제 앱 화면 시연

`SixthSense_실제앱_v0.2.mp4` — 1280×720, 2분 27초, 알림음 포함

- **오른쪽 앱 화면은 0.2.0 소스를 그대로 실행해 그린 실제 화면**입니다. 에뮬레이터 없이 Robolectric으로 MainActivity를 실행하고, 판단 엔진 결과를 앱의 실제 데이터 통로(AssistBus)로 0.1초마다 넣으며 화면을 녹화했습니다.
- 구성:
  - 0.2.0 정지 화면 3장 (차량 보조 모드, 내게 맞는 알림, 체험 모드)
  - 시나리오 1: 부산 센텀시티 3D 주행 (색각이상, "지금 신호 확인" 포함)
  - 시나리오 2: 청각장애 (전체 화면 강조 켬)
- 다시 만들기:
  ```bash
  ./gradlew :app:testDebugUnitTest --tests '*DemoRecordingTest*' -Precord=true   # 실제 화면 녹화 (app/build/recording)
  ./gradlew :demo:renderAppVideo
  ```
