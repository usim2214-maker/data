# 시연 영상

`모두의운전석_시연.mp4` — 1280×720, 30fps, 2분 55초, 알림음 포함

- 앱과 **같은 판단 엔진**(`DrivingAssistEngine`)으로 시나리오를 돌려 렌더링했습니다. 알림 시점·전달 감각·문구는 실제 앱 동작과 같습니다.
- 전방 영상은 **합성 영상**입니다 (Pleos 공개 API에 카메라 미제공). 영상 안에 이 사실을 표기했습니다.
- 알림음은 앱의 실제 소리 패턴입니다. 음성 안내는 자막("음성 안내 …")으로 표시했습니다.
- 다시 만들기: `./gradlew :demo:renderVideo` (ffmpeg, 나눔 글꼴 필요)

## 챕터 (유튜브 설명란에 붙여 넣기)

```
0:00 모두의 운전석 소개
0:06 운전자 특성별 알림 방식
0:12 질문형 첫 설정과 소리 테스트 (내 귀에 맞춘 알림음)
0:27 시나리오 1 색각이상 · 정차 후 출발 ("지금 신호?" 0:39, 운전하며 익히기 0:43)
0:52 시나리오 2 색각이상 · 적색 신호 놓침 (반응 시간까지 고려한 긴급 경고)
1:07 시나리오 3 색각이상 · 황색 딜레마 구간
1:19 시나리오 4 색각이상 · 신호등이 화면 밖으로 (모르면 모른다고 답함 1:34)
1:37 시나리오 5 청각장애 · 소리 경고 시각화 (사이렌 감지, 계속 남는 위험 표시)
2:20 시나리오 6 주의력·저시력 · 야간 도착 (뒷좌석 확인, 주행 요약)
2:46 사용 SDK와 안전·사용자 맞춤 설계
```

## 내레이션 대본 (직접 녹음할 경우)

| 시간 | 내레이션 |
|---|---|
| 0:00 | 자동차는 신호등의 색, 경고음, 작은 경고등처럼 한 가지 감각으로 정보를 줍니다. 모두의 운전석은 이 정보를 운전자에게 맞는 다른 감각으로 바꿔 전달합니다. |
| 0:06 | 운전자가 자기 특성을 고르면, 켤 기능과 알림을 전달할 감각이 정해집니다. |
| 0:12 | 처음 실행하면 장애 이름 대신 겪는 상황으로 묻고, 차 스피커로 소리를 들려줍니다. 낮은 소리만 들리는 운전자에게는 낮고 큰 알림음을, 전혀 못 듣는 운전자에게는 화면 알림을 맞춰 줍니다. |
| 0:30 | 색각이상 운전자입니다. 헷갈릴 땐 '지금 신호' 버튼을 누르면 확실할 때만 답해 줍니다. 처음 몇 번은 소리의 뜻도 함께 알려 줍니다. 황색에는 한 음이 길게, 빨간불에는 세 음이 내려가고, 초록불에는 두 음이 올라갑니다. 초록불은 빨간불보다 더 확실할 때만 확정합니다. |
| 0:56 | 빨간불을 놓치고 접근합니다. 신호등 크기로 거리를 재서, 처음에는 차분하게 안내하고, 감속하지 않아 강한 제동이 필요해지면 그때 긴급 경고를 합니다. |
| 1:10 | 정지선 바로 앞에서 황색이 켜지면, 급정거로 뒤차와 부딪히지 않도록 '정지' 대신 '주의해서 진행'이라고 안내합니다. 교차로에 들어간 뒤의 빨간불에는 경고하지 않습니다. |
| 1:22 | 정지선에 바짝 서서 신호등이 화면에서 사라졌습니다. 앱은 침묵하지 않고 직접 확인하라고 알리고, 물어봐도 모르는 것은 모른다고 답합니다. |
| 1:40 | 청각장애 운전자입니다. 벨트 경고음, 내비 음성, 사이렌, 방향지시등 소리를 모두 화면 깜빡임과 큰 글씨로 바꿉니다. 실내 마이크로 긴급차량 사이렌을 감지합니다. |
| 2:24 | 저시력·고령 운전자입니다. 전조등이 꺼져 있으면 음성으로 알려주고, 동시에 나온 덜 중요한 알림은 화면에만 띄웁니다. 주차하면 뒷좌석을 확인하라고 알리고, 주행 요약을 가족과 공유할 수 있습니다. |
| 2:46 | Pleos Vehicle State와 NaviHelper로 카메라 없이도 지금 동작하고, 카메라가 열리면 신호 인식을 실제 영상으로 바로 전환합니다. |
